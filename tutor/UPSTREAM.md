# Upstream tutor

The zedtutor lesson content is derived from the Vim Tutor distributed with Vim.

## Source

- Project: Vim
- Source file: `runtime/tutor/tutor1`
- Upstream revision: `b87f133b0724f7328e7dd41dd611af67f4ae3e39`

The original tutor has been adapted for use with Zed's Vim mode.

Changes include:

- replacing Vim-specific startup and shutdown instructions
- removing or adapting commands unsupported by Zed
- adapting file and command-palette behavior
- adding Zed-specific navigation and editing lessons
