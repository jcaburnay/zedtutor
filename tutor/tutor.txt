Welcome to zedtutor.

This file is meant to be edited. Do the exercises directly in this buffer.
If something goes wrong, quit without worrying and run `zedtutor` again to get
another fresh copy.

Before starting:

  1. Make sure Zed Vim mode is enabled.
  2. Press <Esc> so you are in Normal mode.
  3. Avoid the mouse while doing the exercises.

Notation used here:

  <Esc>     press the Escape key
  <Enter>   press Enter/Return
  <C-r>     hold Control and press r

LESSON 2: INSERTING TEXT
-------------------------------------------------------------------------------

Normal mode is for commands. Insert mode is for typing text.

  i     insert before the cursor
  a     append after the cursor
  I     insert at the first non-blank character of the line
  A     append at the end of the line
  <Esc> return to Normal mode

LESSON 4: WORD MOTIONS
-------------------------------------------------------------------------------

These motions become much more useful than repeatedly pressing h or l:

  w     move to the start of the next word
  b     move to the start of the previous word
  e     move to the end of the word
  0     move to the start of the line
  ^     move to the first non-blank character
  $     move to the end of the line

LESSON 5: OPERATORS + MOTIONS
-------------------------------------------------------------------------------

Many Vim commands form a small language:

  operator + motion

The delete operator is d.

  dw    delete from the cursor through the next word boundary
  de    delete through the end of the word
  d$    delete from the cursor to the end of the line
  dd    delete the whole line

Exercise 5.1
Use dw to remove the word "unwanted".

Exercise 5.2

Exercise 5.3
Delete the entire line marked DELETE ME with dd.

DELETE ME
keep this line too

The change operator c works similarly to d, but enters Insert mode afterward:

  cw    change a word
  c$    change to end of line
  cc    change a whole line

LESSON 7: YANK AND PUT
-------------------------------------------------------------------------------

Vim calls copying "yanking" and pasting "putting".

  yy    yank the current line
  yw    yank a word
  p     put after the cursor / below the current line
  P     put before the cursor / above the current line

LESSON 9: VISUAL MODE
-------------------------------------------------------------------------------

Visual mode lets you select text before operating on it.

  v     character-wise Visual mode
  V     line-wise Visual mode
  <Esc> leave Visual mode

You can combine a Visual selection with commands such as d, y, or c.

-------------------------------------------------------------------------------
LESSON 10: A FEW ZED-SPECIFIC BASICS
-------------------------------------------------------------------------------

Zed's Vim mode is not a one-to-one copy of Vim. It keeps familiar Vim behavior
where it fits and integrates it with Zed's own editor features.

Useful Ex-style commands supported by Zed include:

  :w       save the current file
  :q       close the current buffer
  :wq      save and close
  :vs      split vertically
  :sp      split horizontally
  :ls      show open buffers
  :Explore open the project panel

Exercise 10.1
Type :w and press <Enter> to save this practice session.

Optional exploration:

  - Try :vs and :sp, then close the extra pane when finished.
  - Try :ls to view your open buffers.
  - Try :Explore to open Zed's project panel.

Zed also provides Vim-style integrations beyond classic motions. Once the core
lessons feel comfortable, useful areas to explore include text objects,
surrounding text, commenting with gcc/gc, pane navigation, diagnostics,
language-server navigation, and multiple cursors.
