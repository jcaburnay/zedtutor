     Zed includes a Vim mode that brings Vim's modal editing model into Zed.
     This tutor teaches the core motions and editing commands by having you
     use them directly inside this file.

     The approximate time required to complete this chapter is 30-45 minutes,
     depending on how much time you spend experimenting.

     ATTENTION:
     The commands in the lessons will modify this text.  That is expected.
     When you run `zedtutor`, a fresh practice copy is created, so you can
     experiment freely without changing the pristine tutor shipped with the
     project.

     This tutor is designed to teach by use.  Execute the commands in each
     lesson instead of trying to memorize everything at once.

     Before starting:
       1. Make sure Zed Vim mode is enabled.
       2. Press <ESC> so you are in Normal mode.
       3. Press j enough times to move down to Lesson 1.1.1.

     This tutorial is adapted from the Vim Tutor distributed with Vim.
     See the repository's attribution and Vim License files for details.

		     Lesson 1.2.3: ON OPERATORS AND MOTIONS


  Many commands that change text are made from an operator and a motion.
  The format for a delete command with the  d  delete operator is as follows:

  	d   motion

  Where:
    d      - is the delete operator.
    motion - is what the operator will operate on (listed below).

  A short list of motions:
    w - until the start of the next word, EXCLUDING its first character.
    e - to the end of the current word, INCLUDING the last character.
    $ - to the end of the line, INCLUDING the last character.

  Thus typing  de  will delete from the cursor to the end of the word.

NOTE:  Pressing just the motion while in Normal mode without an operator will
       move the cursor as specified.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  1. Move the cursor to the start of the line below marked --->.

  2. Type  2w  to move the cursor two words forward.

  3. Type  3e  to move the cursor to the end of the third word forward.

  4. Type  0  (zero) to move to the start of the line.

  5. Repeat steps 2 and 3 with different numbers.

---> This is just a line with words you can move around in.

  6. Move on to lesson 1.2.5.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
		     Lesson 1.2.5: USING A COUNT TO DELETE MORE


   ** Typing a number with an operator repeats it that many times. **

  In the combination of the delete operator and a motion mentioned above you
  insert a count before the motion to delete more:
	 d   number   motion

  1. Move the cursor to the first UPPER CASE word in the line marked --->.

  2. Type  d2w  to delete the two UPPER CASE words.

  3. Repeat steps 1 and 2 with a different count to delete the consecutive
     UPPER CASE words with one command.

--->  this ABC DE line FGHI JK LMN OP of words is Q RS TUV cleaned up.

			 Lesson 1.2.6: OPERATING ON LINES


		   ** Type  dd   to delete a whole line. **

  Due to the frequency of whole line deletion, the designers of Vi decided
  it would be easier to simply type two d's to delete a line.

  1. Move the cursor to the second line in the phrase below.
  2. Type  dd  to delete the line.
  3. Now move to the fourth line.
  4. Type   2dd   to delete two lines.

--->  1)  Roses are red,
--->  2)  Mud is fun,
--->  3)  Violets are blue,
--->  4)  I have a car,
--->  5)  Clocks tell time,
--->  6)  Sugar is sweet
--->  7)  And so are you.

Doubling to operate on a line also works for operators mentioned below.

  4. Fix several errors on the line using  x .

  5. Type  u  a few times to undo those changes one by one.

  6. Type CTRL-R (hold Control while pressing R) a few times to redo them.

  7. These are very useful commands.  Now move on to the Lesson 1.2 Summary.

			       Lesson 1.2 SUMMARY

  1. To delete from the cursor up to the next word type:        dw
  2. To delete from the cursor up to the end of the word type:  de
  3. To delete from the cursor to the end of a line type:       d$

	       operator   [number]   motion

			Lesson 1.4.2: THE SEARCH COMMAND


     ** Type  /  followed by a phrase to search forward. **

  1. In Normal mode type the  /  character.

  2. Type  errroor  and press <ENTER>.

  3. To search for the same phrase again, type  n .
     To search for it in the opposite direction, type  N .

  4. To search backward for a phrase, use  ?  instead of  / .

  5. CTRL-O goes back to older jump locations and CTRL-I goes forward through
     newer jump locations.  Try them after moving between a few search matches.

--->  "errroor" is not the way to spell error;  errroor is an error.

		   Lesson 1.4.3: MATCHING BRACKETS


	      ** Type  %  to jump to a matching bracket. **

  1. Place the cursor on any (, [, or { in the line below marked --->.

  2. Type  % .

  3. The cursor moves to the corresponding matching delimiter.

  4. Type  %  again to move back.

  5. Move to another delimiter and try it again.

---> This ( is a test line with ('s, ['s ] and {'s } in it. ))

NOTE: Zed's Vim mode uses semantic parsing where it makes sense, so % can be
      language-aware when you use it in source-code files.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
		      Lesson 1.4.4: THE SUBSTITUTE COMMAND


	** Type  :s/old/new/g  to substitute 'new' for 'old'. **

  1. Move the cursor to the line below marked --->.

  2. Type:

	:s/thee/the <ENTER>

     This changes the first occurrence of "thee" on the current line.

  3. Now type:

	:s/thee/the/g <ENTER>

     The g flag changes every occurrence on the current line.

---> thee best time to see thee flowers is in thee spring.

  4. To replace text across a range of lines, use:

	:#,#s/old/new/g

     where #,# are the first and last line numbers.

  5. To replace throughout the entire file, use:

	:%s/old/new/g

NOTE: Zed implements Vim-style substitution using Zed's regular-expression
      engine.  Most simple substitutions look the same, but advanced regex
      syntax differs from Vim.  In particular, Zed uses normal capture groups
      like (text) and replacement groups such as $1.

			       Lesson 1.4 SUMMARY


  1. G moves to the end of the file.
     gg moves to the beginning.
     number G moves to that line number.
     :number also jumps to a line in Zed.

  2. /phrase searches forward.
     ?phrase searches backward.
     n repeats a search in the same direction.
     N repeats a search in the opposite direction.
     CTRL-O moves to an older jump; CTRL-I moves to a newer jump.

  3. % jumps between matching delimiters and may use Zed's semantic parsing.

  4. Substitute commands include:

	:s/old/new		replace the first match on the current line
	:s/old/new/g		replace all matches on the current line
	:#,#s/old/new/g		replace within a line range
	:%s/old/new/g		replace throughout the file

     Zed's advanced regular-expression syntax differs slightly from Vim's.

		      Lesson 1.7.2: ZED-SPECIFIC VIM FEATURES


   ** Zed adds modern editor features while keeping Vim's editing model. **

  Zed's Vim mode includes functionality that often requires plugins in Vim.

  Some useful examples are:

	ys	surround a text object
	cs	change surrounding characters
	ds	delete surrounding characters

	gc	comment or uncomment a Visual selection
	gcc	comment or uncomment the current line

  Zed also provides syntax-aware motions and text objects through its parser.

  These commands are most useful in source-code files, where Zed knows the
  language and syntax.

NOTE: Comment commands depend on the current file type, so they may not visibly
      change this plain-text tutor.

			     Lesson 1.7.3: NAVIGATING CODE IN ZED


   ** Zed connects Vim-style shortcuts to language-server navigation. **

  When editing a supported source-code file, try:

	gd	go to definition
	gD	go to declaration
	gy	go to type definition
	gI	go to implementation

	gs	find a symbol in the current file
	gS	find a symbol in the project

	]d	go to the next diagnostic
	[d	go to the previous diagnostic
	gh	show inline error information
	g.	open code actions

  These are Zed-specific integrations rather than classic Vim commands.
  They let you keep a modal editing workflow while using Zed's language-server
  features.

  You do not need to practice these commands inside this plain-text tutor.
  Return to them when you are editing a real codebase.

			       Lesson 1.7 SUMMARY


  1. In Normal mode, : opens Zed's command palette.

  2. Zed supports familiar Vim-style commands for saving, closing buffers,
     splitting panes, showing buffers, and opening panels.

  3. Zed includes built-in surround and commenting commands such as:
	ys	cs	ds	gc	gcc

  4. Zed integrates Vim-style shortcuts with language-server navigation:
	gd	gD	gy	gI	gs	gS

  5. Diagnostics can be navigated with:
	]d	[d

  6. Zed's Vim mode is intentionally not a one-to-one copy of Vim.  It keeps
     the modal editing model while using Zed's own parser, search system,
     multiple cursors, language servers, panes, and panels.
